# Gallery image files

Upload the following four files into this `images/` folder:
- `serial-aprs-is.png` — actual USB serial log, GitHub Actions UF2
- `pico2w-board.jpg` — Pico 2 W photograph
- `android-bluetooth.png` — paired Android device list
- `android-tethering.png` — Android Bluetooth tethering settings

The main README and the Japanese README use a 2×2 HTML thumbnail table linking to the full-size images.

The images were supplied by the project author on 2026-10-04. Hardware photo optimized to JPEG, other screenshots kept as PNG.
